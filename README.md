# 🧮 Calculator — MK1

A sleek, dark-themed calculator web app built with HTML, CSS, and JavaScript.

---

## ✨ Features

- Basic operations — Addition, Subtraction, Multiplication, Division
- Percentage calculation
- Backspace / delete last digit
- Expression display (shows full equation as you type)
- Cyan flash animation on equals
- Full keyboard support
- Responsive and clean dark UI

---

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript

---

## 🚀 How to Run

1. Clone or download this repository
2. Open `calculator.html` in any browser
3. Or use **Live Server** in VS Code for best experience

```bash
git clone https://github.com/Divyakumbar/Calculator.git
```

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0-9` | Input number |
| `+` `-` `*` `/` | Operators |
| `Enter` or `=` | Calculate |
| `Backspace` | Delete last digit |
| `Escape` | Clear all |
| `%` | Percentage |
